# Thaler’s Homebrew tap

```sh
brew install thaler-sh/tap/thaler
```

The Thaler CLI: figures from SEC filings, each with the filing it came
from. The formula is written by the CLI’s release job when a version is
promoted to the stable channel; it installs the same signed archives as
`curl -fsSL https://thaler.sh/install | sh`. More at https://thaler.sh/cli.
